FINDINGS (each traced to rows above and to a change in the chain)
  F1  Same problem, two labels: MP4 export stuck at 99%
      rows changed: rv_4e1bf0fa7c
      found: rv_aba4ca6b7b got 'mp4 export stuck at 99%' and rv_4e1bf0fa7c got 'mp4 export stalls'. Both reviews say MP4 export stops at 99% and never finishes. Split, each counts 1 (low); together they are 2 (medium).
      fix:   Fixed theme catalogue in tagging_schema.py: one entry 'mp4 export stuck at 99%'.
  F2  Same problem, two labels: Pro shown only at download
      rows changed: rv_6866864537
      found: rv_6866864537 got 'background remover not marked pro' while three other reviews with the same problem (Pro revealed only at save/download) got 'pro items not marked'. The count shows 3 + 1 instead of 4.
      fix:   Fixed theme catalogue: one entry 'pro items not marked', defined to cover any element, font or tool the user only learns is Pro at save or download.
  F3  Same problem, three labels: app crashes
      rows changed: rv_e5da5d4c58, rv_0adbf47db0, rv_49906f6ab7
      found: rv_e5da5d4c58 'crash on template tap', rv_0adbf47db0 'app closes when adding photos' and rv_49906f6ab7 'freezes and crashes on text-heavy designs' all describe the app closing itself. The labels name the trigger instead of the problem, so each counts 1 (low); together they are 3 (medium).
      fix:   Fixed theme catalogue: one entry 'app crashes', defined as the app closing itself whatever triggered it.
  F4  Request theme worded as a fault
      rows changed: rv_b4b6fd5646
      found: rv_b4b6fd5646 is correctly a feature_request, but its theme 'keyboard shortcuts not working' reads like a bug, which contradicts the label on the dashboard card.
      fix:   Fixed theme catalogue: request themes are named as the wish ('keyboard shortcuts on ipad'), and the schema rejects a theme from the wrong category.
  Root cause of F1-F3: the chain tags each review in a separate call, so the model never sees the themes it gave earlier reviews. The old rule 'use the same wording every time' could not be followed. The fix replaces free-text themes with a fixed catalogue the model must pick from.

  - Text lag in rv_cdf86c6e0b (second issue) is not counted: the one-winner rule picks the PDF export failure, which the review mentions first. No change.
